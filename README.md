# Learning Management System

## Problem

The goal of this project was to build a Learning Management System that supports different users involved in the learning process.

The system was designed for three main roles:

- **Admins:** manage courses by announcing, approving, and deleting courses.
- **Instructors:** add lessons and quizzes, and track students' progress and completion.
- **Students:** access available courses, view grades, and receive certificates.

---

## What I Did

I developed the system using Java and applied Object-Oriented Programming concepts to organize the application.

I created a parent `User` class and built separate classes for `Admin`, `Instructor`, and `Student`. Each class had its own responsibilities depending on the actions that role needed to perform.

I also used JSON files for storing and managing data and implemented features related to courses, lessons, quizzes, progress tracking, grades, and certificates.

---

## Outcome

The final system was organized and functional. After debugging and improving different parts of the project, it worked correctly without remaining issues.

This project improved my understanding of Java, OOP concepts, class design, and managing a larger software system.

# FastAPI Task API

## Problem

The goal of this project was to create a task management API that allows users to create, read, update, and delete tasks through CRUD operations.

The project helped me learn how backend APIs are structured and how different parts of a REST API communicate.

---

## What I Did

I built the API using Python and FastAPI.

I created REST API endpoints for managing tasks and implemented CRUD operations. I used Pydantic models for data validation and defining the API structure.

I also used Swagger UI for testing and documenting the API, which helped me understand how APIs can be developed and tested.

---

## Outcome

The API was successfully built and worked correctly.

Although I started the project without previous knowledge about APIs, I learned how REST APIs work, how endpoints are designed, and how backend applications are structured.
